What this demonstrates

The browser runs LVGL widgets and the C++ controller in WebAssembly. Reusable PNG control skins and icons, JPEG cabin artwork and short frame sequences give the design a practical path to an embedded display.

Measured browser build: 4.43 MiB of packed assets and 443 KiB of WebAssembly. Example MCU budget: a 480 × 40 RGB565 draw buffer uses 37.5 KiB, or 598.1 KiB for one full 480 × 638 buffer. These estimates exclude image decoding, caches, fonts, and application RAM. Firmware fit and performance depend on the target board and display driver.
